# Sources for the final research report

Checked on 7 November 2026. Experimental measurements in this project come from its own saved result files; published results from other systems are not reported as this project's results.

1. Yizhu Wang, Haoyu Zhai, Chenkai Wang, Qingying Hao, Nick A. Cohen, Roopa Foulger, Jonathan A. Handler and Gang Wang. **Can You Walk Me Through It? Explainable SMS Phishing Detection using LLM-based Agents.** SOUPS 2025, pp. 37–56. [Paper and publication record](https://www.usenix.org/conference/soups2025/presentation/wang). Section 4.1 describes the released sample, relabelling, active-URL selection, and personal-archive contribution. The paper's malicious class combines phishing and spam; its published accuracy is not directly comparable with this project's smishing-only target.
2. SmishX authors. [Research repository pinned to commit 116a8c827741e0572563f678d25ed04306b1e3ff](https://github.com/yizhu-joy/SmishX/tree/116a8c827741e0572563f678d25ed04306b1e3ff). The repository has an MIT notice. Raw corpus files are kept outside this application and source package; the repository notice does not independently establish rights over every upstream message.
3. Tiago A. Almeida and José María Gómez Hidalgo. **SMS Spam Collection.** UCI Machine Learning Repository, 2011. [Dataset and CC BY 4.0 attribution](https://archive.ics.uci.edu/dataset/228/sms+spam+collection), [DOI](https://doi.org/10.24432/C5CC84). This is the separate historical spam baseline.
4. Sentence Transformers. [all-MiniLM-L6-v2 model card](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2/blob/1110a243fdf4706b3f48f1d95db1a4f5529b4d41/README.md). English encoder, Apache 2.0, 384-dimensional embeddings, default truncation at 256 word pieces. This project freezes the encoder and trains a logistic-regression head; it does not fine-tune the transformer.
5. scikit-learn developers. [Probability calibration](https://scikit-learn.org/stable/modules/calibration.html). Classifier training and calibration require separate observations. The Brier score reflects more than calibration alone.
6. scikit-learn developers. [StratifiedGroupKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.StratifiedGroupKFold.html). Group-disjoint splitting aims to preserve label proportions while keeping groups intact; exact partition sizes can differ from the target proportions.

Additional monitoring-method sources are documented with the implemented experiment in `MONITORING.md`. Related work supports methodological choices; it does not validate this application on future scams or prove usefulness through 2030.
